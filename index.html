GNU AWK Features Supported

Directives

  • @include "file.awk" - Includes external file
  • @load "ext" - Loads dynamic C extension
  • @namespace "name" - Sets identifier namespace

Special Variables

  • ARGIND - Index in ARGV of current file
  • ERRNO - System error string for failed I/O
  • FPAT - Regex describing field contents
  • FIELDWIDTHS - Space separated field column widths
  • FUNCTAB / SYMTAB - Array of defined functions/variables

Built-in Functions

  • gensub(r, s, h [, t]) - Powerful substitution
  • patsplit(s, a [, r]) - Split by regex matching
  • asort(src [, dest]) - Sort array by value
  • asorti(src [, dest]) - Sort array by index
  • strftime(fmt, ts) - Format timestamp
  • typeof(x) / isarray(x) - Dynamic type inspection
